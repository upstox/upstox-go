# Upstox Go SDK

[![Go Reference](https://pkg.go.dev/badge/github.com/upstox/upstox-go.svg)](https://pkg.go.dev/github.com/upstox/upstox-go/upstox_client)

## Introduction

The official Go client for communicating with the <a href="https://upstox.com/trading-api/">Upstox API</a>.

Upstox API is a set of rest APIs that provide data required to build a complete investment and trading platform. Execute orders in real time, manage user portfolio, stream live market data (using Websocket), and more, with the easy to understand API collection.

- Package version: 1.0.0
- Build package: io.swagger.codegen.v3.generators.go.GoClientCodegen

This Go package is automatically generated by [Swagger Codegen](https://github.com/swagger-api/swagger-codegen) 3.0.79, the same generator as the other Upstox SDKs.

## Installation & Usage

```sh
go get github.com/upstox/upstox-go
```

Then import the packages. The layout mirrors the other Upstox SDKs:

| Package | Contents |
|---|---|
| `github.com/upstox/upstox-go/upstox_client` | `Configuration`, `APIClient`, errors, sandbox mode |
| `github.com/upstox/upstox-go/upstox_client/api` | one service per API group (`OrderApi`, `UserApi`, `MarketQuoteV3Api`, ...) |
| `github.com/upstox/upstox-go/upstox_client/models` | request and response types |
| `github.com/upstox/upstox-go/upstox_client/feeder` | WebSocket streamers (`MarketDataStreamerV3`, `PortfolioDataStreamer`) |

```go
import (
	"github.com/upstox/upstox-go/upstox_client"
	"github.com/upstox/upstox-go/upstox_client/api"
	"github.com/upstox/upstox-go/upstox_client/models"
)
```

## Getting Started

```go
package main

import (
	"context"
	"errors"
	"fmt"

	"github.com/upstox/upstox-go/upstox_client"
	"github.com/upstox/upstox-go/upstox_client/api"
)

func main() {
	cfg := upstox_client.NewConfiguration()
	cfg.AccessToken = "{your_access_token}"
	client := upstox_client.NewAPIClient(cfg)

	userApi := api.NewUserApi(client)
	resp, _, err := userApi.GetProfile(context.Background())
	if err != nil {
		var apiErr upstox_client.GenericSwaggerError
		if errors.As(err, &apiErr) {
			fmt.Println("Error:", string(apiErr.Body()))
			return
		}
		fmt.Println("Error:", err)
		return
	}
	if resp.Data != nil {
		fmt.Println(resp.Data.UserName)
	}
}
```

Create a service from the client with `api.New<Service>Api(client)` (like Python's `upstox_client.OrderApi(api_client)`). Every call has the same shape: `<service>.<Method>(ctx, <required params>, opts)`, returning the decoded response, the raw `*http.Response` and an error.
Optional parameters go in a `*api.<Service>Api<Method>Opts` struct built with [`github.com/antihax/optional`](https://pkg.go.dev/github.com/antihax/optional), e.g. `&api.OrderV3ApiPlaceOrderOpts{XAlgoName: optional.NewString("my-algo")}`; pass `nil` when there are none.
Models in `models` are plain structs with exported fields; `Data` is often a pointer, so nil-check it.
API errors are `upstox_client.GenericSwaggerError`; `Body()` holds the Upstox error code and message.

Order place, modify and cancel calls are sent to `api-hft.upstox.com`; everything else, including US stock orders, goes to `api.upstox.com`.

## Sandbox Mode

We recommend using the sandbox environment for testing purposes. To enable sandbox mode, create the configuration with `upstox_client.NewSandboxConfiguration()`.

```go
package main

import (
	"context"
	"errors"
	"fmt"

	"github.com/upstox/upstox-go/upstox_client"
	"github.com/upstox/upstox-go/upstox_client/api"
	"github.com/upstox/upstox-go/upstox_client/models"
)

func main() {
	cfg := upstox_client.NewSandboxConfiguration()
	cfg.AccessToken = "{your_sandbox_access_token}"
	client := upstox_client.NewAPIClient(cfg)

	order := models.PlaceOrderV3Request{
		Quantity:          1,
		Product:           "D",
		Validity:          "DAY",
		Price:             9.12,
		Tag:               "string",
		InstrumentToken:   "NSE_EQ|INE669E01016",
		OrderType:         "LIMIT",
		TransactionType:   "BUY",
		DisclosedQuantity: 0,
		TriggerPrice:      0,
		IsAmo:             true,
		Slice:             true,
	}
	resp, _, err := api.NewOrderV3Api(client).PlaceOrder(context.Background(), order, nil)
	if err != nil {
		var apiErr upstox_client.GenericSwaggerError
		if errors.As(err, &apiErr) {
			fmt.Println("Error:", string(apiErr.Body()))
			return
		}
		fmt.Println("Error:", err)
		return
	}
	if resp.Data != nil {
		fmt.Println(resp.Data.OrderIds)
	}
}
```

Calls the sandbox does not support return an error without being sent.
To learn more about the sandbox environment and the available sandbox APIs, please visit the [Upstox API documentation - Sandbox](https://upstox.com/developer/api-documentation/sandbox).

## Market Protection

Market and stop-loss market orders accept an optional market price protection percentage (`-1` lets the exchange decide, up to `25`). It is available on `models.PlaceOrderV3Request`, `models.ModifyOrderRequest`, `models.MultiOrderRequest` and GTT rules:

```go
order.MarketProtection = -1
```

## Documentation for Feeder Functions

Connecting to the WebSocket for market and portfolio updates is streamlined through two primary Feeder functions:

1. **MarketDataStreamerV3**: Offers real-time market updates, providing a seamless way to receive instantaneous information on various market instruments.
2. **PortfolioDataStreamer**: Delivers updates related to the user's orders, enhancing the ability to track order status and portfolio changes effectively.

Both live in the `github.com/upstox/upstox-go/upstox_client/feeder` package and authenticate with the configuration's `AccessToken`.

## Detailed Explanation of Feeder Interface

### MarketDataStreamerV3

The `MarketDataStreamerV3` connects to the market WebSocket and delivers protobuf-decoded updates for the subscribed instruments:

```go
package main

import (
	"fmt"
	"os"
	"os/signal"

	"github.com/upstox/upstox-go/upstox_client"
	"github.com/upstox/upstox-go/upstox_client/feeder"
	"github.com/upstox/upstox-go/upstox_client/feeder/marketdatav3"
)

func main() {
	cfg := upstox_client.NewConfiguration()
	cfg.AccessToken = "{your_access_token}"

	streamer, err := feeder.NewMarketDataStreamerV3(cfg, []string{"NSE_INDEX|Nifty 50", "NSE_INDEX|Nifty Bank"}, feeder.ModeFull)
	if err != nil {
		fmt.Println("Error:", err)
		return
	}
	streamer.OnMessage(func(update *marketdatav3.FeedResponse) {
		fmt.Println(update)
	})
	if err := streamer.Connect(); err != nil {
		fmt.Println("Error:", err)
		return
	}

	stop := make(chan os.Signal, 1)
	signal.Notify(stop, os.Interrupt)
	<-stop
	streamer.Disconnect()
}
```

#### Modes

- **ModeLTPC**: Provides information solely about the most recent trade, encompassing details such as the last trade price, time of the last trade, quantity traded, and the closing price from the previous day.
- **ModeFull**: The full option offers comprehensive information, including the latest trade prices, D5 depth, 1-minute, 30-minute, and daily candlestick data, along with some additional details.
- **ModeOptionGreeks**: Contains only option greeks.
- **ModeFullD30**: Includes Full mode data plus 30 market level quotes.

#### Functions

1. **NewMarketDataStreamerV3(cfg, instrumentKeys, mode)**: Creates the streamer; the keys are subscribed in `mode` once connected. Returns an error for an invalid mode.
2. **Connect()**: Establishes the WebSocket connection and starts reading in the background.
3. **Subscribe(instrumentKeys, mode)**: Subscribes to updates for the given instrument keys in the specified mode.
4. **Unsubscribe(instrumentKeys)**: Stops updates for the specified instrument keys.
5. **ChangeMode(instrumentKeys, mode)**: Switches the mode for already subscribed instrument keys.
6. **Disconnect()**: Ends the active WebSocket connection; no reconnect follows.
7. **AutoReconnect(enable, interval, retryCount)**: Configures reconnection after an unexpected close. On by default: every second, up to 5 attempts. Subscriptions are re-sent after a reconnect.
8. **ClearSubscriptions()**: Forgets remembered subscriptions so they are not re-sent on reconnect.

#### Events/Listeners

Register callbacks before `Connect`. They run on the streamer's read goroutine, so keep them short.

- **OnOpen(func())**: Called on every successful (re)connect.
- **OnClose(func(code int, text string))**: Called when the connection closes.
- **OnMessage(func(*marketdatav3.FeedResponse))**: Delivers market updates.
- **OnError(func(error))**: Called on connection and decoding errors.
- **OnReconnecting(func(attempt int))**: Called before each reconnect attempt.
- **OnAutoReconnectStopped(func(reason string))**: Called when reconnecting gives up (retries exhausted, 401) or is disabled.

1. Subscribing, changing mode and unsubscribing after connecting

```go
package main

import (
	"fmt"
	"time"

	"github.com/upstox/upstox-go/upstox_client"
	"github.com/upstox/upstox-go/upstox_client/feeder"
	"github.com/upstox/upstox-go/upstox_client/feeder/marketdatav3"
)

func main() {
	cfg := upstox_client.NewConfiguration()
	cfg.AccessToken = "{your_access_token}"

	streamer, err := feeder.NewMarketDataStreamerV3(cfg, []string{"NSE_INDEX|Nifty 50"}, feeder.ModeFull)
	if err != nil {
		fmt.Println("Error:", err)
		return
	}
	streamer.OnOpen(func() { fmt.Println("Connected") })
	streamer.OnMessage(func(update *marketdatav3.FeedResponse) { fmt.Println(update) })
	streamer.OnError(func(err error) { fmt.Println("Error:", err) })
	if err := streamer.Connect(); err != nil {
		fmt.Println("Error:", err)
		return
	}

	time.Sleep(5 * time.Second)
	streamer.Subscribe([]string{"NSE_INDEX|Nifty Bank"}, feeder.ModeLTPC)

	time.Sleep(5 * time.Second)
	streamer.ChangeMode([]string{"NSE_INDEX|Nifty Bank"}, feeder.ModeFull)

	time.Sleep(5 * time.Second)
	streamer.Unsubscribe([]string{"NSE_INDEX|Nifty 50", "NSE_INDEX|Nifty Bank"})
	streamer.Disconnect()
}
```

2. Tuning auto-reconnect

```go
package main

import (
	"fmt"
	"os"
	"os/signal"
	"time"

	"github.com/upstox/upstox-go/upstox_client"
	"github.com/upstox/upstox-go/upstox_client/feeder"
)

func main() {
	cfg := upstox_client.NewConfiguration()
	cfg.AccessToken = "{your_access_token}"

	streamer, err := feeder.NewMarketDataStreamerV3(cfg, []string{"NSE_INDEX|Nifty 50"}, feeder.ModeLTPC)
	if err != nil {
		fmt.Println("Error:", err)
		return
	}
	streamer.AutoReconnect(true, 10*time.Second, 3)
	streamer.OnClose(func(code int, text string) { fmt.Println("Closed:", code, text) })
	streamer.OnReconnecting(func(attempt int) { fmt.Printf("Reconnecting, attempt %d\n", attempt) })
	streamer.OnAutoReconnectStopped(func(reason string) { fmt.Println("Auto reconnect stopped:", reason) })
	if err := streamer.Connect(); err != nil {
		fmt.Println("Error:", err)
		return
	}

	stop := make(chan os.Signal, 1)
	signal.Notify(stop, os.Interrupt)
	<-stop
	streamer.Disconnect()
}
```

### PortfolioDataStreamer

The `PortfolioDataStreamer` delivers order, position, holding and GTT order updates as JSON messages:

```go
package main

import (
	"fmt"
	"os"
	"os/signal"

	"github.com/upstox/upstox-go/upstox_client"
	"github.com/upstox/upstox-go/upstox_client/feeder"
)

func main() {
	cfg := upstox_client.NewConfiguration()
	cfg.AccessToken = "{your_access_token}"

	streamer, err := feeder.NewPortfolioDataStreamer(cfg, feeder.PortfolioUpdates{
		Order:    true,
		Position: true,
		Holding:  true,
		GTTOrder: true,
	})
	if err != nil {
		fmt.Println("Error:", err)
		return
	}
	streamer.OnMessage(func(update []byte) { fmt.Println(string(update)) })
	if err := streamer.Connect(); err != nil {
		fmt.Println("Error:", err)
		return
	}

	stop := make(chan os.Signal, 1)
	signal.Notify(stop, os.Interrupt)
	<-stop
	streamer.Disconnect()
}
```

#### Constructor Parameters

`NewPortfolioDataStreamer(cfg, updates)` returns the streamer and an error, where `updates` is a `feeder.PortfolioUpdates`:

- **Order**: Order updates.
- **Position**: Position updates.
- **Holding**: Holding updates.
- **GTTOrder**: GTT order updates.

#### Functions

1. **Connect()**: Establishes the WebSocket connection.
2. **Disconnect()**: Ends the active WebSocket connection.
3. **AutoReconnect(enable, interval, retryCount)**: Configures reconnection, as for `MarketDataStreamerV3`.

#### Events/Listeners

- **OnOpen(func())**, **OnClose(func(code int, text string))**, **OnError(func(error))**, **OnReconnecting(func(attempt int))**, **OnAutoReconnectStopped(func(reason string))**: Same as `MarketDataStreamerV3`.
- **OnMessage(func([]byte))**: Delivers each portfolio update as raw JSON.

## Testing

Put your access token in [`test/sdk_tests/data_token.go`](test/sdk_tests/data_token.go) (`AccessToken`, `SandboxAccessToken`), as with `data_token.py` in the Python SDK, or set `UPSTOX_ACCESS_TOKEN` / `UPSTOX_SANDBOX_ACCESS_TOKEN`, which take precedence. Never commit a filled-in `data_token.go`.

```sh
go test -race ./...                              # unit tests, no network
go test -tags sdk ./test/sdk_tests/ -v           # live API test suite
go run test/sdk_tests/sanity.go                # sanity script, port of Python's sanity.py
go run test/sdk_tests/sandbox_sanity.go        # sandbox sanity script
```

See [test/sdk_tests/README.md](test/sdk_tests/README.md) for the options; calls that place or cancel real orders, exit positions or change account settings are off unless explicitly enabled.

## Development

The REST client — `upstox_client/client.go`, `configuration.go`, `response.go`, `upstox_client/api/` and `upstox_client/models/` — plus `docs/` and the spec copy `api/swagger.yaml` are generated from the Upstox OpenAPI spec with swagger-codegen 3.0.79 (`-l go`), like the other Upstox SDKs. Do not edit them by hand; they are regenerated by the SDK sync process, which adapts the spec, runs swagger-codegen, re-applies the Upstox hooks (access token, HFT routing, sandbox, SDK headers) and splits the output into the `api` and `models` packages.

Hand-written code lives in `upstox_client/upstox.go`, `upstox_client/upstox_test.go` and `upstox_client/feeder/`.

To regenerate the market data protobuf types:

```sh
cd upstox_client/feeder/marketdatav3
protoc --go_out=. --go_opt=paths=source_relative MarketDataFeedV3.proto
```
